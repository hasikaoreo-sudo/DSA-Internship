# DSA Internship – Week 1

This repository contains my Week 1 Data Structures and Algorithms (DSA) internship assignments and mini project implemented in C++.

## Topics Covered

- Introduction to Data Structures and Algorithms
- Time and Space Complexity
- Big O Notation
- Arrays and Strings
- Linear Search
- Binary Search
- Bubble Sort
- Selection Sort

## Assignments

### 1. Linear Search
A C++ program that searches for a given element in an array using Linear Search.

**Time Complexity:** O(n)

### 2. Binary Search
A C++ program that searches for an element in a sorted array using Binary Search.

**Time Complexity:** O(log n)

### 3. Bubble Sort
A C++ program that sorts an array using Bubble Sort and counts the number of swaps.

**Time Complexity:** O(n²)

### 4. Reverse an Array
A C++ program that reverses an array without using an extra array.

**Time Complexity:** O(n)

**Extra Space:** O(1)

## Mini Project – Student Marks Analyzer

The Student Marks Analyzer accepts marks of N students, sorts the marks, displays the top 3 marks, and calculates the average score.

### Features

- Input marks for N students
- Validate marks between 0 and 100
- Sort marks from highest to lowest
- Display the top 3 marks
- Calculate and display the average score
